# LivePulse News - Next.js (Auto-updating)

Quick start:
1. Create `.env.local` with:
   NEWSAPI_KEY=your_newsapi_key_here
   NEXT_PUBLIC_BASEURL=http://localhost:3000

2. Install & run locally:
   npm install
   npm run dev
   (Open http://localhost:3000)

3. Deploy to Vercel:
   - Push this folder to GitHub or upload ZIP to Vercel.
   - In Vercel Project Settings add environment variable NEWSAPI_KEY.
